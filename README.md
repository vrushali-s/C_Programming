# C Programming - Logic Building

Welcome to the **C Programming** repository. This project is a structured collection of programs, assignments, and practical exercises designed to strengthen core problem-solving skills and master foundational programming logic using the C language.

## 📂 Repository Structure

All coursework is organized sequentially inside the `Assignments` directory. Each subfolder contains the relevant source code files (`.c`) along with any specific problem descriptions.

*   `Assignments/`
    *   `Assignment_1/` — Foundational concepts, operators, and basic logic.
    *   `Assignment_2/` — Conditional control flow (if-else, switch-case).
    *   `Assignment_3/` — Iterative loops and pattern printing structures.
    *   *...future assignments will follow this sequential naming convention (`Assignment_N/`)*

## 🚀 Getting Started

Follow these instructions to set up and run any program from this repository on your local machine.

### 1. Prerequisites
Ensure you have a standard **C Compiler (GCC)** installed:
*   **Windows**: [MinGW-w64](https://mingw-w64.org) or WSL.
*   **macOS**: Open terminal and run `xcode-select --install`.
*   **Linux**: Run `sudo apt update && sudo apt install build-essential`.

### 2. Clone the Repository
```bash
git clone https://github.com
cd C_Programming
```

### 3. Compile and Run
Navigate into the specific assignment folder you wish to test, compile the source file, and execute the binary:

```bash
# Move to the desired assignment directory
cd Assignments/Assignment_1

# Compile the C file
gcc source_file.c -o program

# Execute the compiled binary
# On Windows:
program.exe

# On Linux/macOS:
./program
```

## 🛠️ Core Concepts Covered
*   **Basics:** Data types, standard input/output (`scanf`, `printf`), and typecasting.
*   **Operators:** Arithmetic, relational, logical, and bitwise manipulation.
*   **Control Flow:** Decisional trees, nesting, and multi-way branching.
*   **Iteration:** Advanced looping logic, series generation, and matrix-based patterns.
